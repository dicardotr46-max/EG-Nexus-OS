## 2023-11-01 - Missing Debouncing on Search Inputs
**Learning:** Functions like `renderAppsCatalog` and `renderHomeChatList` iterate and filter over large data sets in the app state. They are bound to `oninput` events in the UI without debouncing, meaning they block the main thread on every keystroke, which is a significant bottleneck on mobile devices (the target platform).
**Action:** Wrap these heavy render functions in the `oninput` handler with the global `debounce` utility (e.g., `debounce(renderAppsCatalog, 300)`). The repository memory explicitly mentions: "To optimize search inputs and prevent main-thread blocking in the monolithic `index.html`, a global `debounce` utility function is used to wrap expensive UI rendering functions (like `renderHomeChatList` and `renderAppsCatalog`) during rapid `oninput` events." This implies `debounce` is available or should be implemented.
